# 🔐 MERN Authentication System

A simple and secure **User Authentication System** built with the **MERN Stack (MongoDB, Express, React, Node.js)**.  
This project includes **user registration, login, JWT authentication, and protected routes**.

---

## 🚀 Features

- 🧾 User Registration (`/signup`)
- 🔑 User Login (`/login`)
- 🔒 JWT-based Authentication
- ⚙️ Password Hashing using bcrypt
- 🔐 Protected Routes (accessible only to authenticated users)
- 🌐 RESTful API Architecture

---

## 🛠️ Tech Stack

**Frontend:** React.js  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT (JSON Web Token), bcrypt
